Got Questions?

Frequently Asked Questions

Everything you need to know about using Livestock Express.

1. How do I install the APK on my mobile phone?

Click the download button above to save the `.apk` file to your phone. Tap the downloaded file to install. If prompted by Android, allow installation from unknown sources for this browser or file manager.

2. Why does the ID verification check for blur and image quality?

To maintain absolute transparency and prevent fraudulent registrations across Alaminos City, our capture system evaluates image clarity and blur standards before accepting identification documents.

3. How does the live GPS tracking work?

Once the inspection is approved and the seller taps "Dispatch", the mobile app securely streams the seller's live GPS coordinates to Firestore. The admin panel at the municipal office renders these updates on a real-time radar map.

4. Who can use Livestock Express v1.0.0?

The platform is built for verified local livestock farmers, registered buyers across Pangasinan, and administrators at the Alaminos City Veterinary Office.
